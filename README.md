# EduStories

Единая образовательная платформа с двумя направлениями: интерактивной библиотекой историй и сервисом обучения с заказами, мастерами и личным кабинетом.

При открытии сайта посетитель попадает на общую стартовую страницу EduStories:

- **«Перейти к обучению»** открывает доску учебных поручений, быстрый расчёт и создание заказа;
- **«Открыть библиотеку»** открывает ранее созданный мир книг, карту историй, Кси и читательские разделы.

В учебном направлении авторизованный пользователь может создать заказ, увидеть его в личном кабинете, переключать статусы, просматривать предложения мастеров и сообщения. Данные демонстрационной версии сохраняются в браузере.

В меню библиотеки раздел **«Книгочей»** объединяет три направления:

- **Путь героя** — интерактивная карта;
- **Гильдии** — выбор Круга Историй, совместные задания и обсуждения;
- **Коллекционер** — переворачиваемые карточки, полученные за задания.

На карте Кси сопровождает читателя в чате. После выбора точки под картой открываются задания с полями ответа; ответы, переписка, опыт и полученные карточки сохраняются в браузере автоматически.

Светлая и тёмная темы переключаются в шапке, выбор темы сохраняется. Иллюстрации оптимизированы в WebP, а дополнительные страницы загружаются только при открытии, поэтому стартовая версия сайта весит менее 1 МБ.

## Новые разделы и доступ

- **«Главная»** теперь является первым экраном сайта и знакомит посетителя с миром, персонажами и основными механиками EduStories.
- **«Контракты»** открывают Зал Нотариуса Пергамента: доступные, активные, выполненные и просроченные обязательства.
- Кнопка **«Алхимия»** открывает интерактивную лабораторию Мастера Флягиуса: ингредиенты, рецепты, котёл и гримуар. Состояние лаборатории сохраняется в браузере.
- Профиль читателя открывается по кнопке пользователя в правой части шапки после входа.
- Раздел **«Коллекционер»** доступен только авторизованным читателям. Для гостя сайт сначала откроет форму входа.
- Вступительный свиток, диалоги Кси и выбор героя перенесены в **«Путь героя»**. Гость может познакомиться с картой, но точки, задания и сохранение ответов открываются только после входа.

## Самый простой способ опубликовать на GitHub Pages

Готовая версия сайта находится в папке `docs`. Никакая сборка на GitHub не требуется.

1. Загрузите **всё содержимое проекта** в корень репозитория GitHub. Папка `docs` обязательно должна попасть в репозиторий.
2. Откройте репозиторий на GitHub и перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`;
   - **Branch:** `main`;
   - **Folder:** `/docs`.
4. Нажмите **Save**.
5. Подождите 1–5 минут и обновите страницу **Settings → Pages**. Там появится ссылка на сайт.

Важно: файлы `docs/index.html` и `docs/assets/...` должны отображаться на GitHub. Если в репозитории находится только папка `Книгочей`, а уже внутри неё лежит `docs`, GitHub Pages сайт не найдёт. Содержимое `Книгочей` нужно загрузить непосредственно в корень репозитория.

## Автоматическая публикация

В проекте также оставлен workflow `.github/workflows/deploy-pages.yml`. Если в **Settings → Pages** выбрать `GitHub Actions`, GitHub соберёт и опубликует проект автоматически после отправки изменений в `main` или `master`.

Используйте только один вариант источника публикации: либо `main /docs`, либо `GitHub Actions`.

### Если GitHub сообщает `due to in progress deployment`

Это означает, что предыдущая публикация Pages ещё выполняется. Откройте
**Actions → Deploy EduStories to GitHub Pages**, дождитесь завершения текущего
запуска или отмените зависший запуск вручную. Не запускайте публикацию повторно,
пока у предыдущей отображается статус **In progress**.

Workflow проекта ставит следующие публикации в очередь и больше не отменяет
активное развёртывание. В **Settings → Pages → Build and deployment** при
использовании workflow должен быть выбран только источник **GitHub Actions**.
